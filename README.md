# Sentiment Analisis Ulasan JMO Mobile dengan XGBoost

Repository ini berisi proyek analisis sentimen ulasan pengguna aplikasi **JMO (Jamsostek Mobile)** menggunakan algoritma Machine Learning **XGBoost**.

##  Alur Kerja
1. **Data Preprocessing**: Cleaning, case folding, filtering, dan stemming ulasan.
2. **Feature Extraction**: Pembobotan kata menggunakan
3. **Modelling & Evaluation**: Klasifikasi sentimen menggunakan **XGBoost** dan evaluasi performa model

##  Teknologi & Library
* **Python** (Pandas, NumPy, Scikit-Learn)
* **XGBoost**
